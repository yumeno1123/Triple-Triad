# 自動デプロイ（GitHub連携）の実装計画

## 1. 目的
Antigravity（AI）がコードを修正した際、手動でファイルをアップロードすることなく、自動的にNetlify上の公開サイトが更新される仕組みを構築します。

## 2. 仕組み
1.  **GitHub**: 世界中の開発者がコードを保存する場所です。ここを保管庫にします。
2.  **Netlifyの連携**: NetlifyがGitHubを監視し、新しいコードが届いたら自動的にサイトを書き換えます。
3.  **Antigravityの操作**: 私がコードを修正した後、「Push（プッシュ）」という操作をすることで、GitHub経由でNetlifyに自動送信されます。

## 3. 手順

### フェーズ1：ツールのインストール（Antigravityが実施）
- `winget` コマンドを使用して、**Git**（コード管理ツール）と **gh**（GitHub操作ツール）をインストールします。

### フェーズ2：保管庫（GitHub）の作成
- GitHubアカウントをお持ちでない場合は作成していただく必要があります。
- その後、私がこのプロジェクト用の保管庫（リポジトリ）を作成し、現在のコードをアップロードします。

### フェーズ3：Netlifyとの接続（ユーザーが実施）
- Netlifyの管理画面で、作成したGitHubのリポジトリと連携する設定を行います（ボタンを数回押すだけです）。

## 4. 期待される効果
以降、私が「対局のバランスを調整しました」といった修正を行うたびに、**数秒〜数分で実際の公開サイトが自動的に最新版にアップデート**されます。

## 5. ユーザーへのお願い
この計画を進めるために、以下のツールのインストールを許可いただけますでしょうか。
- **Git.Git**: コードの変更履歴を記録するツール
- **GitHub.cli**: 私がGitHubを操作するための公式ツール

# バージョン情報表示の実装計画

## 1. 目的
自動デプロイによって「現在の公開サイトがどの時点の修正を反映しているか」をユーザー（制作者）が容易に確認できるようにします。

## 2. 実装内容

### [index.html](file:///C:/Users/Owner/Documents/myproject/Triple%20Triad/index.html) の修正
- タイトル画面（`#screen-title`）の下部またはロゴ付近に、バージョン番号を表示する小さな要素を追加します。
- 今回のバージョンを `v1.0.0 (2026.02.27)` と定義します。

### [style.css](file:///C:/Users/Owner/Documents/myproject/Triple%20Triad/style.css) の修正
- バージョン情報がゲームデザインを邪魔しないよう、小さく、かつ透過度を持たせたスタイルを定義します。

## 3. 運用ルール
- 今後、大きな機能追加や重要な修正を行うたびに、私が自動でこのバージョン番号をカウントアップ（v1.0.1, v1.1.0...）します。

## 4. 検証プラン
- [ ] 画面上にバージョン番号が正しく表示されていること。
- [ ] 自動デプロイ後、公開URLにアクセスして番号が更新されていることを確認。

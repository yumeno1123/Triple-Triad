# デッキ選択画面のレベル別表示対応

## 1. 目的
ゲーム開始時のデッキ選択画面において、カードが煩雑に並んでいる現状を改善し、コレクション画面同様にレベル（Lv.1〜10）ごとに区切って表示することで、目当てのカードを探しやすくします。

## 2. 変更内容

### [main.js](file:///C:/Users/Owner/Documents/myproject/Triple%20Triad/main.js) 的改修
- `renderDeckAvailableCards(matchType)` を刷新します。
- `CARD_DATA` をレベル1から10まで順に走査し、各レベルのカードを抽出します。
- 各レベルに対して、ヘッダー（例：「LEVEL 1」）と、カードを並べるためのサブグリッド要素を作成します。
- 既存のクリックイベントやバッジ更新処理は維持します。

### [style.css](file:///C:/Users/Owner/Documents/myproject/Triple%20Triad/style.css) 的改修
- デッキ編集画面のサブグリッドにも、コレクション用のグリッドスタイル（`grid-template-columns` 等）が適用されるようにします。
- `#deck-available-grid` 自体の `display: grid` を解除し、中のサブグリッドが適切に機能するように調整します。

## 3. 検証プラン
1. フリーモードで開始し、全カードがレベルごとに整理されていることを確認。
2. アドバンスモードで開始し、所持しているカードのみが対応するレベルのセクションに表示されていることを確認。
3. ルーレット演出やゲーム開始が正常に動作することを確認。

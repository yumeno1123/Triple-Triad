# GitHub Pages への移行計画

## 1. 目的
Netlify の月間ビルド制限（クレジット）を回避し、より自由頻繁にゲームを更新・公開できるようにするため、ホスティング先を GitHub Pages へ移行します。

## 2. 移行手順

### フェーズ 1: ローカルの変更を反映
現在ローカルにある「レベル8以上の金縁」「レベル10の豪華装飾」といった最新の修正を、すべて GitHub の `main` ブランチへプッシュします。

### フェーズ 2: GitHub Pages の有効化
ブラウザ上で GitHub リポジトリの設定（Settings）を開き、GitHub Pages を有効にします。
- **Source**: Deploy from a branch
- **Branch**: main / (root)

### フェーズ 3: 動作確認
GitHub Pages が生成する URL（例: `https://yumeno1123.github.io/Triple-Triad/`）にアクセスし、正しくゲームが動作することを確認します。

## 3. 利点
- **制限なし**: ビルド時間を気にする必要がなくなります。
- **即時反映**: プッシュしてから公開までの時間が短縮されます。
- **一元管理**: GitHub だけで完結するため、運用がシンプルになります。

## 4. ユーザーへのお願い
移行作業の一環として、GitHub の設定操作が必要になる場合があります（私が自動で行うことも試みますが、最終確認をお願いすることがあります）。

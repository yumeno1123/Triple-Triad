# カード全110種類の網羅（原作再現）

## 1. 目的
原作『ファイナルファンタジーVIII』に登場する全110種類のカード（レベル1〜10）を全て実装し、コレクションやゲームプレイの奥深さを最大化します。

## 2. 実装計画

### [cards.js](file:///C:/Users/Owner/Documents/myproject/Triple%20Triad/cards.js) 的刷新
- 現在の `CARD_DATA`（30枚程度）を破棄し、全110枚のデータを新規に挿入します。
- 各カードの `id`, `level`, `name`, `stats` (上, 右, 下, 左) を原作通りに設定します。
- レベル区分は以下の通りです：
  - **レベル 1〜5**: 一般モンスター
  - **レベル 6〜7**: ボスモンスター
  - **レベル 8〜9**: ガーディアンフォース (GF)
  - **レベル 10**: 主要キャラクター

- **Lv 3**: アルマダード, トライフェイス, フォスティトガロン, スノーライオン, オチュー, クリープス, ヘッジヴァイパー, ケルベロス (幼い版), トライエッジ, デスマシーン, ワイルドマジロ

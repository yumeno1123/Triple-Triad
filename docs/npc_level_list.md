# ストーリーモード NPCレベル・ルールリスト

各エリアに登場するNPCのレベル（強さの目安）と、対戦時に適用される特殊ルールをまとめました。

## NPCレベルについて
レベルが高いほど、NPCはより強力なカード（数字が大きいカード）を使用してきます。
- **チュートリアル**: 固定のデッキを使用してルールを教えるためのステージです。
- **Lv 1〜4**: 初心者向けの強さです。
- **Lv 5〜7**: 中級者向けの強さで、特殊ルールも増えてきます。
- **Lv 8〜10**: 上級者向けです。非常に強力なレアカードを使用してくることがあります。

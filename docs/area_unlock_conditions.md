# ストーリーモード エリア開放条件リスト

ストーリーモードの各エリアを解放するための条件をまとめました。基本的に、前のエリアの最終的なNPC（ボス的存在）を倒すことで次のエリアが解放される仕組みになっています。

## エリア一覧と開放条件

| エリア名 | 開放条件 | 詳細 |
| :--- | :--- | :--- |
| **チュートリアル** | なし | 最初からプレイ可能です。 |
| **バラムガーデン** | 「チュートリアル教官」に勝利 | 最初（npc_00）のチュートリアルをクリアすると解放されます。 |
| **バラムガーデン (CC団)** | 「シド学園長」に勝利 | バラムガーデン本線のボスである「シド学園長」を倒すと解放されます。 |
| **ドール** | 「シュウ」に勝利 | バラムガーデンのボス手前に登場する「シュウ」を倒すと解放されます。 |
| **ガルバディア** | 「画家の孫」に勝利 | ドールのボス手前に登場する「画家の孫」を倒すと解放されます。 |
| **F.H.** | 「黒い服の男」に勝利 | ガルバディアのボス手前に登場する「黒い服の男」を倒すと解放されます。 |
| **トラビア** | 「F.H.の整備士」に勝利 | F.H.のボス手前に登場する「F.H.の整備士」を倒すと解放されます。 |
| **エスタ** | 「セルフィの友達」に勝利 | トラビア의 ボス手前に登場する「セルフィの友達」を倒すと解放されます。 |
| **宇宙・月** | 「ちょっと年配の兵士」に勝利 | エスタのボス手前に登場する「ちょっと年配の兵士」を倒すと解放されます。 |

## 各エリアの詳細（NPCの流れ）

*※太字のNPCに勝利すると、次のエリアが解放されます。*

### 1. チュートリアル (`area_tutorial`)
- **チュートリアル教官** ← **バラムガーデン解放条件**
- チュートリアル教官（セイム）
- チュートリアル教官（プラス）
- チュートリアル教官（コンボ）
- チュートリアル教官（ウォールセイム）

### 2. バラムガーデン (`area_balamb_garden`)
- バラムガーデン門下生
- トゥリープFC会員01
- カドワキ先生
- **シュウ** ← **ドール解放条件**
- **シド学園長** ← **バラムガーデン (CC団)解放条件**

### 3. ドール (`area_dollet`)
- ドールのパブのオーナー
- **画家の孫** ← **ガルバディア解放条件**
- カードクイーン

### 4. ガルバディア (`area_galbadia`)
- 駅員
- **黒い服の男** ← **F.H.解放条件**
- カーウェイ大佐

### 5. F.H. (`area_fh`)
- ドープ駅長
- **F.H.の整備士** ← **トラビア解放条件**
- マルティネ

### 6. トラビア (`area_trabia`)
- トラビアの男子生徒
- **セルフィの友達** ← **エスタ解放条件**
- 歌手志望の女子

### 7. エスタ (`area_esthar`)
- 紫の服の女性
- **ちょっと年配の兵士** ← **宇宙・月解放条件**
- オダイン博士

### 8. 宇宙・月 (`area_lunar`)
- 医療クルー
- ピエット
- エルオーネ

### 9. バラムガーデン (CC団) (`area_balamb_cc`)
- ジャック (CC団)
- クラブ (CC団)
- ジョーカー (CC団)
- ダイヤ (CC団)
- スペード (CC団)
- シュウ (CC団・ハート)
- キスティス (CC団・キング)

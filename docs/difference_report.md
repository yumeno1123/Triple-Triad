# トリプルトライアド：原作（FF8）との差異レポート

現在のプロジェクト実装と、原作（ファイナルファンタジーVIII）の「トリプルトライアド」を比較し、仕様の差異や未実装の機能をリストアップしました。

## 1. 盤面とUIのレイアウト
- **手札の配置**:
  - **原作**: 自分の手札は画面右側、相手の手札は画面左側に縦一列で並ぶ。
  - **現状**: 自分の手札は画面下部、相手の手札は画面上部に横一列で並んでいる。
- **カードの視認性**:
  - **原作**: 盤面や手札に置かれているカードは最初から「プレイヤーカラー（赤／青）」の背景に各キャラクターの絵柄が描かれている。
  - **現状**: 汎用的なデザインとなっており、背景色やCSSグラデーションで仮の表現をしている（キャラクター画像や各カード専用のアートワークが存在しない）。

## 2. プレイヤーのアクションと操作感
- **先攻・後攻の決定**:
  - **原作**: ゲーム開始時に「どちらが先攻か」をルーレット等でランダムに決定する演出がある。
  - **現状**: 内部的に `Math.random() < 0.5` で決定しており、画面表示上「TURN: PLAYER X」といきなり始まる。
- **カードの配置操作**:
  - **原作**: コントローラーのカーソル移動でカードを選び、盤面の空きマスを選択して配置する。
  - **現状**: マウスによるクリック操作（手札をクリック→盤面をクリック）。

## 3. カードの特性とデッキ構築
- **エレメンタル（属性）ルール**:
  - **原作**: カード自体に属性（炎、氷、雷など）が付与されているものがあり、盤面の特定マスにも属性アイコンがランダム配置される「エレメンタル」ルールが存在する。属性が一致すると数値にボーナス（+1）、不一致だとペナルティ（-1）がかかる。
  - **現状**: 属性（エレメンタル）の概念、および盤面の属性マス実装が存在しない。
- **デッキ（手札）の選択制限**:
  - **原作**: 手札に同じカードを複数枚（ダブり）入れることができる（所持数分だけ）。
  - **現状**: 手札選択画面（`screen-deck-edit`）において、所持していれば選択できるが、UIの構造上「同じ種類のカードを2枚以上デッキに組み込む」操作が考慮されていない（選択するとトグルで解除されてしまう）。

## 4. 特殊ルールの挙動・仕様
- **ルールの伝播（波及）**:
  - **原作**: 地域（リージョン）ごとに特殊ルールが設定されており、プレイヤーがルールを持ち運んで別の地域に伝播させたり、廃れさせたりするメタゲームシステムがある。
  - **現状**: タイトル画面のチェックボックスでプレイヤーが任意に全ルールをON/OFFする仕組み。
- **ランダムハンド**:
  - **原作**: 手札を自分で選べず、所持カードの中から完全にランダムで5枚選ばれる特殊ルール「ランダムハンド」が存在する。
  - **現状**: 未実装。

## 5. 演出とサウンド
- **BGM / SE**:
  - **原作**: 象徴的なBGM（Shuffle or Boogie）や、カードを置いた際の効果音、カードが裏返る際の特徴的なSEが存在する。
  - **現状**: サウンドアセットがなく、全体的に無音。
- **結果発表のファンファーレ**:
  - **原作**: 勝利時におなじみのファンファーレと共に派手な演出が入る。
  - **現状**: 文字の巨大化やCSSの明滅アニメーションで代用している。

# 実装完了のウォークスルー: NPCレベル設定機能（Phase 34）

CPU戦をもっと楽しく、歯ごたえのあるものにするため、NPCの難易度（レベル）を選択できる機能を実装しました。

## 実施した主な変更

### 1. NPCレベル選択 UI の追加
タイトル画面のマッチタイプ設定の下に、NPCのレベル（LV 1 〜 LV 10）を変更できるスライダーを追加しました。
- スライダーを動かすと、リアルタイムで現在の設定レベルが表示されます。

### 2. 賢い手札生成ロジック (Lv ±1 方式)
NPCの手札が、単純なランダムではなく、**選択されたレベルの ±1 の範囲**のカードから選ばれるようになりました。
- **低レベル (LV 1)**: レベル1〜2の弱いカードが中心になります。
- **中レベル (LV 5)**: レベル4〜6のバランスの取れた手札になります。
- **高レベル (LV 10)**: レベル9〜10の超強力なレアカードばかりを繰り出してきます。

### 3. v1.1.0 へのメジャーアップデート
今回の大きな機能追加に伴い、バージョンを `v1.1.0` へ更新しました。

# CC団イベント 調査レポート

バラムガーデンのカードプレイヤー集団「CC団（Card Club）」に関する現在の実装状況を調査しました。

## 現状の実装状況

現在、コードベース内（`npcs.js`）には以下の状況が確認されました。

### 1. 登録されているメンバー
*   **シュウ (ハート)**
    *   ID: `npc_04`
    *   説明文に「CC団の『ハート』」という記述があります。
    *   セイムルールを好む設定になっています。

### 2. 未実装のメンバー
原作においてCC団を構成する以下のメンバーは、現在NPCとして登録されていません。
*   ジャック
*   クラブ
*   ナイト
*   プリンセス (ダイヤ)
*   ジョーカー
*   キング (クィスティス / シュウ)

### 3. イベント・ロジック
*   **フラグ管理**: CC団を順番に倒していくような専用のフラグ管理ロジック（例：ジャックに勝たないとクラブが出現しない等）は、現在の `main.js` や `game.js` には見当たりません。
*   **出現条件**: 現在、バラムガーデンのNPCは単一の連鎖（門下生 -> 会員01 -> カドワキ先生 -> シュウ -> シド学園長）として実装されており、CC団としての独立したイベントラインにはなっていません。

## 考察と提案

現在のストーリーモードは、エリアごとにNPCを順番に倒していくシンプルな構成になっています。
もし「CC団イベント」を本格的に導入する場合、以下のような追加実装が考えられます。

1.  **メンバーの追加**: ジャック、クラブ、ダイヤ、ジョーカー、キングを新NPCとして追加する。
2.  **専用エリア/カテゴリ**: バラムガーデン内に「CC団」というサブカテゴリを作るか、現在のバラムガーデンのNPC構成をCC団中心に再編する。
3.  **特殊ルール**: 各メンバーごとに、原作に近いルール（例：ダイヤはランダムなど）を割り当てる。

現時点では「シュウがCC団の一員として一般NPCの中に混ざっている」という状態です。
